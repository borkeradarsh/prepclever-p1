# 90 Day Upskilling

Transitioning into an AI role within an Indian Global Capability Center (GCC) requires moving beyond theoretical machine learning into **enterprise execution, domain integration, and MLOps/Agentic architecture**.

This 90-day roadmap is designed to transform software developers, data scientists, and technical analysts into high-value AI professionals for top tier-1 and tier-2 GCC hubs across India.

## 90-Day Upskilling Blueprint

**1.Days 1–30: Enterprise AI Foundations & Core Architectures:**

Focus: Modern AI primitives, RAG patterns, and Vector DBs.

- **Core Focus:** Shift from basic LLM prompts to production-grade enterprise data retrieval and contextual AI pipelines.
- **Key Skills to Master:**
    - **LangChain & LlamaIndex:** Master document loading, chunking strategies, embeddings, and context-window optimization.
    - **Vector Databases:** Hands-on integration with Qdrant, Pinecone, or Milvus for semantic indexing and Hybrid Search (Sparse + Dense Retrieval).
    - **RAG Architectures:** Build advanced Retrieval-Augmented Generation systems using **HyDE** (Hypothetical Document Embeddings) and **Reranking** (Cohere/BGE).
    - **Enterprise Data Compliance:** Understand token management, data privacy, and initial compliance frameworks like DPDP Act.
- **Practical Deliverable:** Build a production-style RAG pipeline capable of querying enterprise internal knowledge bases (PDFs, Confluence pages) with source attribution and hallucination guardrails.

**2.Days 31–60: Autonomous AI Agents & System Design:**

Focus: Agentic workflows, Tool-Calling, and Fine-Tuning.

- **Core Focus:** Transition from simple query-response loops to multi-step agentic execution engines that reflect modern GCC AI workflows.
- **Key Skills to Master:**
    - **Agent Frameworks:** Build multi-agent systems using **CrewAI**, **AutoGen**, or **LangGraph**.
    - **Function Calling & Tools:** Connect LLMs directly to enterprise REST APIs, SQL databases, and automated scripts via structured tool schemas.
    - **Model Customization:** Fine-tune open-source models (Llama 3, Mistral) using **QLoRA** and **PEFT** on specialized datasets.
    - **System Design for GenAI:** Design modular fallback routines (e.g., streaming, cache hit layer using Redis, and dynamic model routing).
- **Practical Deliverable:** Develop an Autonomous Financial/IT Support Agent that parses complex user tickets, executes database queries via tool-calling, and triggers simulated downstream enterprise workflows.

**3.Days 61–90: MLOps, Governance & Enterprise Positioning:**

Focus: Production deployment, cost control, and business translation.

- **Core Focus:** Scale AI systems into enterprise-grade production environments with robust monitoring, drift detection, and governance controls.
- **Key Skills to Master:**
    - **MLOps & Evaluation:** Implement **Ragas** or **TruLens** for automated RAG evaluation (faithfulness, answer relevance, context recall).
    - **Observability & Ops:** Track latency, token costs, and prompt performance using **LangSmith** or **Phoenix**. Set up containerized deployments with Docker and Kubernetes on cloud platforms (AWS Bedrock / Azure OpenAI).
    - **Responsible AI & Governance:** Implement input/output guardrails using **NeMo Guardrails** or **Guardrails AI** to enforce PII masking, safety compliance, and bias mitigation.
    - **GCC Portfolio Prep:** Translate technical execution into business metrics (e.g., reduction in operational cycle time, API cost savings, throughput scalability).
- **Practical Deliverable:** Deploy a containerized, agentic AI microservice to cloud infrastructure complete with CI/CD, live cost tracking, observability dashboards, and strict guardrails.

## 3 Pillars to Nail the GCC AI Interview Process

| **Focus Area** | **What Indian GCC Hiring Managers Look For** | **How to Prove It** |
| --- | --- | --- |
| **1. Business Translation** | Ability to link AI capabilities directly to domain ROI (e.g., BFSI risk analysis, supply chain optimization). | Structure project descriptions around metrics (e.g., *"Reduced query retrieval latency by 40% while cutting token consumption by 25%"*). |
| **2. Production Readiness** | Practical knowledge of failure modes, fallback models, security guardrails, and cloud deployment pipelines. | Bring code architecture diagrams for your portfolio projects; demonstrate awareness of rate-limiting and cost controls. |
| **3. Domain Ownership** | Understanding specific industry context (Healthcare compliance, Retail analytics, Global Financial Risk). | Tailor your portfolio capstone projects to match the targeted GCC's primary domain (e.g., Healthcare RAG vs. Fintech Agent). |
